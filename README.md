# POE Companion

The application and its contributor instructions are in [`Path of Exile App/`](Path%20of%20Exile%20App/README.md). The app is a local-first React frontend with a Node server and offline data; it does not use a cloud backend.

Start it with `Path of Exile App/Start Crafting.cmd` or `npm start` from that folder, then open **http://127.0.0.1:4317/**. Keep using this origin for existing browser saves.

Before making changes, read the project [README](Path%20of%20Exile%20App/README.md), [start guide](Path%20of%20Exile%20App/START-HERE.md), and [current handoff](Path%20of%20Exile%20App/docs/HANDOFF.md). Do not commit or push unless the user asks.
