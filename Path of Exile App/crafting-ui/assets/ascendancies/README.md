# Ascendancy artwork

Unmodified `src/TreeData/Classes*.png` images extracted from the preserved local Path of Building archive. Exact source paths and SHA-256 hashes are recorded in provenance.json. Game artwork belongs to Grinding Gear Games; existing upstream license/source materials remain in the archive and calculation-engine/reference/. No artwork was generated or downloaded. CSS provides the icon framing and banner fade.

Only archive assets matching a supported ascendancy by exact name are shown. Unavailable portraits use the existing character-initial fallback; no other ascendancy is substituted.

Portrait-prefixed PNGs are the original face-focused small icons matching the user's supplied reference, cached from image links on https://poedb.tw/us/Character_class. URLs and hashes are in portrait-provenance.json. These replace whole-disc art for small icons, preserving the unmodified full artwork for banners. Warden retains its own archived image with reviewed framing; Raider is not substituted. Ascendant's archive asset is a blank disc, so the genuine reference portrait is used instead. No files were generated or repainted.
