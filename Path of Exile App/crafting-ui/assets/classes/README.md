# Base class icons

Unmodified Path of Building archived `src/TreeData/center<class>.png` class-start emblems, including the actual class face. Exact paths and hashes are in provenance.json. Game artwork belongs to Grinding Gear Games. Source archive and upstream license materials are preserved. These are base-class emblems, not another ascendancy's portrait or generated art.

The portrait-prefixed PNGs are the original class face portraits matching the user's supplied reference, cached from the image links on https://poedb.tw/us/Character_class. URLs and hashes are in portrait-provenance.json. These now supply the UI's small icons. Original archive emblems remain preserved and are not substituted for faces. Game art remains GGG property; runtime is entirely offline.
