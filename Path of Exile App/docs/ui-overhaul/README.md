# UI overhaul design history

This folder preserves design references, earlier requirements, and the Character pilot record. It is historical documentation, not a map of the current frontend. The application now runs in the React renderer under `renderer/src/`; the retired vanilla shell and its screen controllers were removed.

For current code ownership and run instructions, see the project [README](../../README.md) and [file organization](../FILE-ORGANIZATION.md). For the current migration and verification boundaries, see [React migration](../REACT-MIGRATION.md) and [React QA](../REACT-QA.md).

The reference images, design brief, pilot notes, and checklist remain as provenance for decisions made during the transition. File paths and implementation steps in those records may describe the removed vanilla UI.
